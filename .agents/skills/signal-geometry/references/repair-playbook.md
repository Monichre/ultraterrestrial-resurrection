# Repair playbook

Read this only after a candidate fails a critical gate. Choose the single largest defect and apply the matching correction. Preserve the rest of the prompt.

| Failure signal | Prompt correction |
| --- | --- |
| Background looks flat and digital | Specify full-frame uncoated matte stock, fine irregular fibers, subtle dry grain, and texture visible only at full size. |
| Paper looks vintage, dirty, or theatrical | Specify newly milled clean paper, even coloration, restrained natural grain, and a flat orthographic scan. Remove aging language. |
| Image is too dense | Reduce primitive and path count by 40%-60%, remove the weakest supporting family, and restore 70%-95% quiet background. |
| Several ideas compete | Keep the strongest transformation verb and delete every form that does not participate in that event. |
| Image reads like UI or an infographic | Convert panels, axes, and charts into unlabeled topology; keep only abstract frames, nodes, routes, or measures. |
| Image reads like a glowing HUD | Replace glow and luminous effects with dry graphite-gray hairlines, matte paper, and off-white anchors. |
| Color becomes decorative | Return to grayscale and reserve one pin-sized accent for the semantic focal event. |
| Fine lines tangle or break | Reduce crossings, use fewer paths, widen separation, and establish one consistent primary line weight. |
| Geometry disappears at thumbnail size | Enlarge the main relation or strengthen one anchor while keeping mark coverage low. |
| Stray or pseudo-text appears | State `zero text, zero letters, zero numerals, zero symbols resembling writing` and remove label-like frames. |
| Portrait output looks cropped | Recompose on a 4:5 vertical field with vertically staged geometry and balanced top/bottom quiet space. |
| Candidate resembles a quality anchor | Rebuild its anchor delta with three stronger axis changes, then regenerate. |
