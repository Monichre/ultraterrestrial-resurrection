# GSAP Animation Library

A comprehensive, modular animation system built with GSAP, React, and TypeScript.

## 🎯 Quick Start

```tsx
// Import what you need
import { TextScramble } from '@/lib/animations'
import { useScrambleText } from '@/lib/animations/hooks'
import { TerminalPreloader } from '@/components/animations'

// Use it
<TextScramble text="HELLO WORLD" duration={2000} />
```

## 🚀 Performance Tips

1. **Use constants** - Avoid hardcoding animation values
2. **Memoize callbacks** - Use `useCallback` for event handlers
3. **Limit simultaneous animations** - Don't animate 100+ elements at once
4. **Enable hardware acceleration** - Use `will-change` CSS
5. **Clean up timelines** - Hooks handle this automatically

## 🐛 Troubleshooting

### Animation Not Playing?
- Check if timeline is paused
- Verify refs are attached
- Ensure plugins are loaded

### Text Not Scrambling?
- Confirm `scramble={true}` attribute
- Check `scrambleChars` prop
- Verify ScrambleTextPlugin loaded

### Performance Issues?
- Reduce glitch count
- Increase stagger delay
- Limit concurrent animations
