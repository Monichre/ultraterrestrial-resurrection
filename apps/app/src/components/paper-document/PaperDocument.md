# PaperDocument

Refined 2026-07-19 for real paper / field-note materiality.

## Look

- Warm cream stock (`#f4f0e6`) with debut-twill + groove-paper tooth
- Offset under-sheets (slight rotation, darker) for physical stack depth
- Dark drafting desk (`inflicted-grid` + `fabric-of-squares`) behind the page
- Research meta band: date · location · evidentiary badge
- Cormorant title on `variant="research"`

## Props

| Prop | Notes |
|------|--------|
| `variant` | `letter` \| `research` \| `memo` |
| `meta` | `{ date, location, classification }` |
| `lightDesk` | Cream drafting table instead of void desk |
| `embedded` | No full-viewport height |
| `showSignatureImage` | Defaults off for placeholder URLs |

## Storybook

`Documents/PaperDocument` → **Research Note** is the primary refined surface.
