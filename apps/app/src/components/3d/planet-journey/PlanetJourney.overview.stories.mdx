# 🌍 Planet Journey - Complete 3D Animation System

A spectacular 3D space animation system featuring Earth and Moon with GSAP parallax scrolling and stunning visual effects.

## 🚀 Quick Start

The Planet Journey system consists of three main components:

1. **Classic Journey** - Beautiful base experience with smooth animations
2. **Enhanced Odyssey** - Premium version with advanced effects
3. **Showcase Landing** - Marketing page to choose between versions

## 🛠 Technology Stack

### Core 3D Technologies
- **React Three Fiber** ^9.3.0 - React wrapper for Three.js

- **@react-three/drei** ^10.7.4 - Helper components
- **@react-three/postprocessing** ^3.0.4 - Visual effects

- **GSAP** ^3.13.0 - Professional animation library

- **Framer Motion** ^12.23.15 - React animations
- **Framer Motion 3D** ^12.4.13 - 3D motion components

## 🎬 Animation Sequence

### Phase 1: Cosmic Odyssey (0-20% scroll)
- **Camera Position**: Deep space (z: 80)
- **Effects**: Star field initialization, particle systems start
- **Text**: "Journey Through Space" with gradient effects

### Phase 2: Approaching Terra (20-40% scroll)  
- **Camera Movement**: Smooth zoom toward Earth (z: 30)
- **Effects**: Earth comes into view with atmospheric glow
- **Text**: "Approaching Earth" with parallax motion

### Phase 3: World of Wonders (40-60% scroll)
- **Camera Position**: Close Earth encounter (z: 12)
- **Effects**: Cloud layers, detailed surface textures
- **Text**: "Home Planet" with detailed descriptions

### Phase 4: Luna's Grand Entrance (60-80% scroll)
- **Moon Animation**: Dramatic entrance from off-screen
- **Effects**: Trail effects, orbital mechanics begin
- **Text**: "Lunar Companion" with moon details

### Phase 5: Eternal Dance (80-100% scroll)
- **Final View**: Orbital ballet of Earth-Moon system
- **Effects**: Full lighting, shadow mapping, particles
- **Text**: "Cosmic Dance" finale

## 🚨 Known Issues & Solutions

### R3F Hooks Error
**Issue**: `Hooks can only be used within the Canvas component!`
**Solution**: Move camera controller inside Canvas component

### Performance on Mobile
**Issue**: High particle counts cause frame drops
**Solution**: Use performance mode detection and adaptive quality

### Asset Loading
**Issue**: GLB models may not load in some environments  
**Solution**: Proper fallbacks and error boundaries implemented
