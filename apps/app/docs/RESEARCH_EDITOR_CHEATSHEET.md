# Research Editor Cheatsheet
**Date**: June 29, 2025

## Basic Commands

### Text Formatting
- **Bold** - Click Bold button or `Cmd/Ctrl + B`
- **Italic** - Click Italic button or `Cmd/Ctrl + I`  
- **Heading 2** - Click H2 button
- **Bullet List** - Click List button

### Special Features
- **@ Mentions** - Type `@` to search and mention records from the knowledge base
  - Searches across: events, personnel, documents, locations, organizations, topics, sightings, testimonies, artifacts, key-figures, mindmaps, etc.
  - Results show with type badges (e.g., "EVENT", "PERSONNEL")

## AI-Powered Commands (RAG Integration)

### 🤖 Generate
- Click the Generate button
- Enter a prompt when asked
- AI will generate text based on your prompt and insert it at cursor

### 📝 Summarize  
- Select text you want to summarize
- Click the Summarize button
- AI will insert a summary below your selection

### ✅ Fact Check
- Select a claim or statement
- Click the Fact Check button
- AI will verify against knowledge base and insert:
  - ✅ Verified or ❌ Unverified status
  - Explanation of findings
  - Source citations if available

## Research Context Features
- **Auto-insert** - When you select a card in the mind map, its info auto-inserts into the editor
- **Context Panel** - Shows currently selected and pinned cards at bottom of editor
- **RAG Search** - @ mentions are enhanced with AI-powered semantic search

## Tips
- The editor supports full Markdown formatting
- AI commands require connection to the disclosure-rag server
- Selected text is required for Summarize and Fact Check commands
- All AI results are marked with visual indicators (teal badges)
