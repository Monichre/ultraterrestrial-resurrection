# Ultraterrestrial Resurrection - Project Overview

**Project Type**: UFO/UAP Research Platform with AI-powered analysis and spatial intelligence  
**Architecture**: Monorepo with multiple applications and shared packages  
**Language**: TypeScript (Frontend), Python (RAG System)  
**Framework**: Next.js 15.3.5 with React 19.1.0

## Core Purpose

Comprehensive platform for UFO/UAP research featuring:
- Interactive mindmaps with spatial intelligence
- Advanced AI capabilities and document processing
- Multiple RAG (Retrieval-Augmented Generation) backends
- 230,998+ database records across UFO/UAP research entities
- 3D visualizations and data analysis tools

## Project Structure

```
ultraterrestrial-resurrection/
├── apps/
│   ├── app/                 # Main Next.js research platform
│   ├── disclosure-rag/      # Python RAG system with triple backend
│   └── research-canvas/     # TipTap research editor (consolidating)
├── packages/
│   ├── db/                  # Xata database integration (29 models)
│   ├── ai/                  # AI processing components
│   ├── services/            # External service integrations
│   └── knowledge-base/      # Document management
└── docs/                    # Project documentation
```
