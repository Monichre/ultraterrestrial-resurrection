# UAP Classification Quick Reference Guide
*Rapid field assessment tool for researchers*

**Last Updated**: January 5, 2025  
**Purpose**: Fast taxonomical classification during field work

## Primary Classification Decision Tree

```
UAP Observation
    ├── Can be explained by known physics/technology? 
    │   ├── YES → Physical (PH)
    │   └── NO → Continue evaluation
    │
    ├── Evidence suggests psychological/social factors?
    │   ├── YES → Psycho-Social (PSH) 
    │   └── NO → Continue evaluation
    │
    └── Involves phenomena beyond current scientific paradigm?
        └── YES → Meta-Physical (MPH)
```

## Physical (PH) Classifications

### 1.1 Intra-Dimensional (ID) - Within our spacetime

**Quick Indicators:**
- Follows known physics
- Traceable technology signatures
- Geographic/temporal patterns

| Subcategory | Key Markers | Examples |
|-------------|-------------|----------|
| **Prosaic Natural** | Weather patterns, celestial events | Venus, ball lightning, lenticular clouds |
| **Prosaic Human** | Technology signatures, flight patterns | Military aircraft, drones, satellites |
| **Crypto-Terrestrial** | Earth-based but hidden, ancient patterns | Underground bases, breakaway civilizations |
| **Extra-Terrestrial** | Non-human tech, interstellar implications | Classic "flying saucers", alien technology |

### 1.2 Extra-Dimensional (EDH) - From higher dimensions

**Quick Indicators:**
- Impossible geometry/physics
- Dimensional inconsistencies
- Phase transitions

| Subcategory | Key Markers | Examples |
|-------------|-------------|----------|
| **Hyperspace Entity** | Appears/disappears instantly | Beings from "bulk" space |
| **Brane Projections** | Shadow-like manifestations | 2D projections in 3D space |
| **Brane Avatars** | Holographic appearances | Telepresence manifestations |

### 1.3 Inter-Dimensional (IDH) - Between realities

**Quick Indicators:**
- Timeline anomalies
- Parallel reality signatures
- Quantum effects

| Subcategory | Key Markers | Examples |
|-------------|-------------|----------|
| **Multi-Verse** | Portal effects, reality bleeding | Wormhole transits, parallel encounters |
| **Time Travel** | Temporal paradoxes, anachronisms | Future humans, timeline visitors |
| **Scale Invariance** | Quantum macro-effects | Fractal manifestations |

## Ultra-Terrestrial (UTH) Quick Check

**All must be TRUE for UTH classification:**

✓ **Covert Earth Presence** - Hidden from mainstream society  
✓ **Advanced Technology** - Beyond current human capabilities  
✓ **Semi-Permanent** - Long-term residence on/near Earth  
✓ **Non-Human Origin** - Not modern humans or known ancestors  
✓ **Environmental Integration** - Interacts with Earth systems

**Common UTH Indicators:**
- Underground/underwater bases
- Recurring geographic patterns
- Environmental anomalies
- Advanced but Earth-adapted technology
- Historical presence in folklore/accounts

## Field Classification Workflow

### Step 1: Immediate Assessment (1-2 minutes)
1. Document basic facts (time, location, witnesses, conditions)
2. Assign preliminary primary category (PH/PSH/MPH)
3. Note any UTH indicators

### Step 2: Evidence Collection (5-15 minutes)
1. Physical evidence (photos, recordings, traces)
2. Witness statements and credibility assessment
3. Environmental context documentation
4. Technology analysis (if applicable)

### Step 3: Detailed Classification (10-30 minutes)
1. Apply subcategory criteria systematically
2. Consider multiple hypotheses simultaneously
3. Assign confidence levels (1-4)
4. Document classification rationale

### Step 4: Database Entry
1. Enter standardized classification codes
2. Upload evidence with metadata
3. Cross-reference with similar cases
4. Flag for expert review if needed

## Classification Confidence Levels

| Level | Confidence | Criteria | Action Required |
|-------|------------|----------|----------------|
| **1** | 90%+ | Clear evidence, single viable explanation | Standard documentation |
| **2** | 70-89% | Strong evidence, minimal alternative explanations | Additional verification |
| **3** | 50-69% | Multiple viable hypotheses | Extended investigation |
| **4** | <50% | Insufficient or contradictory evidence | Comprehensive analysis needed |

## Common Classification Errors

### Over-Classification
- **Problem**: Jumping to exotic explanations too quickly
- **Solution**: Always eliminate prosaic explanations first

### Under-Classification  
- **Problem**: Dismissing valid anomalous evidence
- **Solution**: Maintain open-minded systematic evaluation

### Single-Hypothesis Bias
- **Problem**: Focusing on one explanation exclusively
- **Solution**: Maintain multiple working hypotheses

### Evidence Contamination
- **Problem**: Allowing preconceptions to influence classification
- **Solution**: Use standardized evaluation criteria

## Emergency Protocols

### High-Strangeness Events
If case exhibits extreme anomalies across multiple categories:
1. **Document everything** - Multiple recording methods
2. **Preserve evidence** - Chain of custody protocols
3. **Protect witnesses** - Privacy and safety measures
4. **Expert notification** - Alert senior researchers immediately
5. **Media management** - Control information release

### Safety Considerations
- **Physical safety** - Unknown technology/entities may pose risks
- **Psychological safety** - Extreme experiences can be traumatic
- **Information security** - Sensitive cases require discretion
- **Legal compliance** - Respect property rights and jurisdictions
