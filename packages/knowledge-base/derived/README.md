# derived/

Regenerable output, not canonical source material. Everything under this
directory (currently `graphify-out/` folders produced by the `/graphify`
skill — `.graphify_ast.json`, `.graphify_chunks.json`, `.graphify_detect.json`,
`.graphify_python`, `.graphify_uncached.txt`) can be deleted at any time and
rebuilt from `sources/` without loss.

Do not treat anything here as an archival record. The canonical intake tree
is `sources/`.
