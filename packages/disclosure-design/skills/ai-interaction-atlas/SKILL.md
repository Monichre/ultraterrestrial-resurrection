# ai-interaction-atlas

A skill for AI interaction design taxonomy - a vocabulary for mapping roles, responsibilities, and decision points in AI systems.

## When to Use

Use this skill when:
- Designing AI-powered product interactions
- Creating a shared vocabulary for AI experiences
- Mapping complex multi-step AI workflows
- Defining AI tasks, human tasks, and system tasks
- Structuring AI decision points in products

## What It Provides

An open-source taxonomy for AI interaction design with six core dimensions:

### 1. AI Tasks
- Classify
- Generate
- Verify
- Transform

### 2. Human Tasks
- Review
- Approve
- Edit
- Compare

### 3. System Tasks
- Routing
- Logging
- State management

### 4. Data Artifacts
- Inputs, outputs, and intermediate results

### 5. Constraints
- Latency
- Privacy
- Cost
- Accuracy

### 6. Touchpoints
- UI
- API
- Notifications
- Integrations

## Use Cases

```
Defining AI agent workflows
Mapping human-AI collaboration patterns
Structuring AI decision points
Designing AI product experiences
Creating shared vocabulary for AI teams
```
