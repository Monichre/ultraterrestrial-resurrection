# Ultraterrestrial Research UI Package

A foundational consolidated package containing the initial organized design direction, agent spec, implementation guidance, component roadmap, visual language, prompt tokens, and review notes for the Ultraterrestrial Research Platform.

This package is an early synthesis of the visual lab, not the entire current canon. The lab's
cross-corpus, agent-loadable grammar lives in [`../../VISUAL_LANGUAGE.md`](../../VISUAL_LANGUAGE.md)
and [`../../language/visual-language.json`](../../language/visual-language.json). New interfaces
must use [`../../skills/visual-language/`](../../skills/visual-language/) so later research can
refine this foundation instead of being trapped by it.

For app work, begin with one of four priority surfaces—Home / Entry, Research Canvas, Archive /
Record, or Spacetime Observatory—then resolve it through the Three Visual Lanes: Core Interface,
Evidence Archive, and Tactical Spatial. The narrower modes in this package remain valuable as
reference families beneath that structure; they are not eight equal app-wide styles.

## Core Principle

> Make the impossible feel investigable.

The platform should feel like a living archive of anomalous intelligence: declassified documentation, forensic field research, mythological pattern recognition, and disclosure-era analysis presented with disciplined investigative credibility.
