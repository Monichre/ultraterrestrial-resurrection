# Design canon

This tree is the **git-tracked design canon** moved from [`docs/design`](docs/design) on 2026-09-13.

It does **not** get:

- treated as the runtime kit ([`packages/disclosure-ui`](packages/disclosure-ui) / `@repo/disclosure-ui`)
- mixed with vault stills, [`packages/disclosure-design/extractions/`](packages/disclosure-design/extractions/), or [`packages/disclosure-design/_corpus/`](packages/disclosure-design/_corpus/)
- imported by [`apps/app`](apps/app)
- merged into the visual lab vault at [`packages/disclosure-design/design/`](packages/disclosure-design/design/)

Lab stills, extractions, and `design/` stay local research. Product UI ships from `@repo/disclosure-ui` only.
