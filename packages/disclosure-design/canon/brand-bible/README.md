# Ultraterrestrial Research UI Package

A consolidated package containing the complete design direction, agent spec, implementation guidance, component roadmap, visual language, prompt tokens, and review notes for the Ultraterrestrial Research Platform.

## Contents

* `00_MASTER_BRAND_BIBLE.md` — complete consolidated visual identity and product direction.
* `01_RESEARCH_UI_AGENT.md` — finalized research UI archival design specialist agent spec.
* `02_IMPLEMENTATION_ROADMAP.md` — prioritized build plan and component checklist.
* `03_POLAROIDS_COMPONENT_SPEC.md` — Polaroid/evidence photography component system.
* `04_DESIGN_REVIEW_NOTES.md` — review of supplied docs and correction notes.
* `05_PROMPT_TOKENS.md` — reusable Ideogram/style prompt tokens.
* `06_DESIGN_TOKENS.ts` — TypeScript design token starter.
* `07_PACKAGE_INDEX.md` — quick navigation and usage instructions.
* `08_PROMPT_LIBRARY/` — reusable prompts, agent personas, and skill definitions.
* `Design Canon/` — maintained source specs: implementation guide, design system, and aesthetic references.

## Core Principle

> Make the impossible feel investigable.

The platform should feel like a living archive of anomalous intelligence: declassified documentation, forensic field research, mythological pattern recognition, and disclosure-era analysis presented with disciplined investigative credibility.
