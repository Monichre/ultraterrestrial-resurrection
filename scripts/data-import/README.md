# UFO Intelligence Data Import

This directory contains scripts for preparing and importing UFO Intelligence timeline data into the Xata database.

## Files

- `prepare-ufo-events.js`: Basic script to process markdown files and prepare events for import.
- `prepare-ufo-events-enhanced.js`: Enhanced script with better duplicate detection and data extraction.
- `import-events-to-xata.js`: Generated by the prepare script, this will import the processed data into Xata.

## Usage

### Step 1: Prepare the Data

Run the enhanced preparation script to parse the markdown files and generate the JSON and CSV data files:

```bash
node scripts/data-import/prepare-ufo-events-enhanced.js
```

This will:
- Parse all UFOsandIntelligence-*.md files in the docs/ufo-intelligence-docs directory
- Extract events with dates, descriptions, and locations
- Generate event fingerprints for duplicate detection
- Extract keywords from descriptions
- Create two output files in the `output` subdirectory:
  - `events.json`: JSON format of all events
  - `events.csv`: CSV format for potential spreadsheet import
- Generate the import script `import-events-to-xata.js` with enhanced duplicate detection

### Step 2: Import to Xata

After reviewing the output files to ensure the data is formatted correctly, you can import the events into Xata:

```bash
node scripts/data-import/import-events-to-xata.js
```

This will:
- Check for duplicate events using multiple methods:
  1. Exact title matching
  2. Event fingerprint matching
  3. Fuzzy title matching for events with similar dates
  4. Regex-based date comparison
- Insert only new unique events into the events table
- Log progress, duplicates, and any errors encountered during import

## Enhanced Duplicate Detection

The enhanced script implements several layers of duplicate detection:

1. **Exact Title Matching**: Simple but effective first check
2. **Fingerprint Matching**: Each event has a generated fingerprint based on date and description snippet
3. **Date-Based Fuzzy Matching**: For events in the same year, compare titles with fuzzy string matching
4. **Regex Pattern Matching**: Extract and compare date components from event titles

This multi-layered approach helps prevent duplicate entries even when titles or descriptions vary slightly.

## Data Structure

The events are processed into the following structure to match the Xata events table schema:

```javascript
{
  title: string,            // Title of the event ("UFO Event YYYY")
  date: string,             // ISO date format (parsed from the event date text)
  description: string,      // Full event description from the markdown
  location: string,         // Extracted location (if available)
  category: string[],       // Categories for the event ["historical", "ufo-sighting"]
  metadata: {               // Additional metadata
    source: string,         // Source of the data
    dateText: string,       // Original date text from the markdown
    originalFormat: string, // Format of the original data ("markdown")
    keywords: string[],     // Extracted keywords from description
    fingerprint: string     // Unique identifier generated from date and description
  }
}
```

## Notes

- The date parsing logic handles various date formats found in the markdown files, including:
  - Years only (e.g., "1945")
  - Years with seasons (e.g., "1945, Summer")
  - Specific dates (e.g., "1945, June 1")
- Location extraction uses multiple pattern matching rules to identify location mentions
- Keyword extraction identifies common UFO-related terms in the description
- The fingerprint generation helps with identifying duplicate events, even with slight variations
