# Components Organization

The project contains a rich collection of UI components organized by purpose and functionality.

## Component Categories

- `animated` - Animation-based components (beams, lists, modals, etc.)
- `backgrounds` - Background elements and patterns
- `globe` - Globe and Earth visualizations
- `sci-fi` - Sci-fi themed components
- `ui` - Core UI components (buttons, cards, tooltips, etc.)
- `timelines` - Timeline visualization components
- `3d` - 3D and spatial components

## Key Component Files

- [apps/app/src/components/ui/button](mdc:ultraterrestrial-resurrection/apps/app/src/components/ui/button) - Button components
- [apps/app/src/components/globe](mdc:ultraterrestrial-resurrection/apps/app/src/components/globe) - Globe visualization
- [apps/app/src/components/ufo](mdc:ultraterrestrial-resurrection/apps/app/src/components/ufo) - UFO visualization components
- [apps/app/src/components/animated](mdc:ultraterrestrial-resurrection/apps/app/src/components/animated) - Animation components

## Component Naming Convention

- React components use PascalCase (e.g., `Button.tsx`)
- Component directories use lowercase with dashes (e.g., `animated-beam`)
- Component hooks use camelCase with "use" prefix (e.g., `useAnimationState.ts`)
