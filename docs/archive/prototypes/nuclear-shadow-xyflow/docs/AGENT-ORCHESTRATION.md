# Agent Orchestration for Guided-Tour Waypoints

The tour runtime is deterministic. Agents prepare and review the data that feeds it; they do not autonomously alter the live route.

## Waypoint production pipeline

```text
FORT / KNAPP
  acquisition and reporting lineage
        |
        v
RUPPELT
  schema-first extraction
        |
        v
MICHEL / MELLON / POPE / HYNEK
  domain analysis
        |
        v
SCULLY
  evidence and counterpoint review
        |
        v
PILKINGTON
  contamination and narrative-mutation review
        |
        v
KEEL
  narrative synthesis
        |
        v
MAJESTIC
  publication QA and route approval
```

## Nuclear Shadow ownership

| Agent | Responsibility |
|---|---|
| MAJESTIC | Final route, gate, and evidence-boundary approval |
| FORT | Archive acquisition |
| KNAPP | Reporting lineage and source development |
| RUPPELT | Claim extraction and normalized records |
| MICHEL | Temporal and geographic structure |
| MELLON | Government programs and institutional inheritance |
| POPE | Official language and jurisdiction analysis |
| HYNEK | Scientific and technical constraint |
| SCULLY | Evidence sufficiency and strongest objection |
| PILKINGTON | Disinformation and narrative contamination |
| MULDER | Pattern proposals, never final findings |
| KEEL | Cohesive synthesis without uncertainty collapse |

## Publication contract

Agents may propose waypoint revisions, but publishing requires:

- Evidence IDs resolve successfully.
- Claims and evidence roles are explicit.
- At least one meaningful counterpoint is present.
- Hypothesis edges are not promoted to established edges.
- MAJESTIC approves the route change.
- Schema changes remain human-approved.
