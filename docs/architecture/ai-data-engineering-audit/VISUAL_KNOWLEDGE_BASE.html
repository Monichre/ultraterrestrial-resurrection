packages/knowledge-base — static corpus vs runtime retrieval

Runtime retrieval does not read this package directly. Ingestion and search go through apps/disclosure-rag (Upstash/pgvector, OpenAI vector store) and app APIs.

Corpus layout

packages/knowledge-base/
  sources/files/     # static documents (case_files, etc.)
  metadata/          # sidecar metadata
  exports/           # export artifacts

Runtime paths (disclosure-rag)

ingest (CLI) → unified_rag_orchestrator
  → Upstash Vector (optional) + pgvector_library + OpenAI vector store
search → same backends (not packages/knowledge-base file reads)

Relationship to mindmap agent

Mindmap file_search uses OpenAI vector store (Assistants), not the knowledge-base folder. Both can index overlapping corpora — alignment is an operational concern.
