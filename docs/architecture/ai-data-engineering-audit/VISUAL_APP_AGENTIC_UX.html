Tool events (mindmap route)

Server emits AgentToolEvent with types: file_search, searchDatabase, web_search, addNodes, addGraphEdges, addUserInputNode, addNextEntitiesToMindMap, updateNodeData.

  • searchDatabase → Xata via askXata / searchXataWithAi (packages/db)
  • file_search → OpenAI vector store (Assistants file_search tool)
  • Graph writes use addNodes / addGraphEdges with parentId for layout

UX gaps vs ai-ux-patterns / building-ai-chat

Partial: Tool progress via EntityAdditionProgress during graph writes; session status on chat route.
Missing / weak: No unified retrieval evidence panel in UI; limited citation/source surfacing; no explicit context budget UI; mock adapters (local-files-adapter, xata-adapter) should not be treated as production retrieval.
