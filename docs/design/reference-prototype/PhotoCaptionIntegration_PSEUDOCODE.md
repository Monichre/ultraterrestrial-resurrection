# Photo Caption Integration

## Goal
Integrate PhotoCaption component into existing document layouts to enhance visual storytelling and provide authentic archival annotations.

## Integration Points
1. DocumentA - Add captions to main scan and sidebar images
2. DocumentB - Add captions to abstract and collage panels
3. UFODispatchDocument - Add caption to weathered Polaroid
4. WeatheredClassifiedDocument - Add caption to photo
5. Vintage Posters - Add captions where images are present

## Implementation Strategy
- Position captions relative to their parent containers
- Use authentic archival language and terminology
- Maintain visual hierarchy with existing elements
- Ensure responsive behavior across screen sizes
