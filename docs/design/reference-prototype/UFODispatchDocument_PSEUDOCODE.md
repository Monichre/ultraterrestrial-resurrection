# UFO Dispatch Document Component

## Goal
Create a Socorro Incident dispatch document component with authentic 1960s police dispatch styling and weathered paper effects.

## Key Features
- Police dispatch script format with timestamps
- Weathered document appearance with coffee stains and fold lines
- Rotated "CLASSIFIED" stamp
- Handwritten notes in cursive
- Weathered Polaroid photo attachment
- Multiple layered aging effects

## Implementation
1. Create TypeScript interface for props
2. Use existing font system (Anton, Special Elite, Caveat)
3. Implement weathered paper textures and stains
4. Add police dispatch content structure
5. Include rotated photo with aging effects
6. Export as reusable component
