## Caption Content Strategy
- **Authentic Language**: Uses period-appropriate technical terminology
- **Evidence-Based**: References specific observations and measurements
- **Classification Levels**: Maintains appropriate security language
- **Witness Integration**: Connects to documented testimony

## Visual Design
- **Consistent Styling**: Semi-transparent backgrounds with backdrop blur
- **Responsive Text**: Smaller text for photos, standard for main images
- **Strategic Positioning**: Avoids interference with existing elements
- **High Z-Index**: Ensures captions appear above all other elements

## Technical Implementation
- **Import Integration**: Added PhotoCaption imports to all relevant components
- **Positioning Classes**: Used Tailwind positioning utilities for precise placement
- **Responsive Behavior**: Captions adapt to different screen sizes
- **Accessibility**: Maintains proper semantic structure with figcaption elements

The integration enhances the documentary authenticity while providing additional context and technical details that support the overall narrative of each document type.
