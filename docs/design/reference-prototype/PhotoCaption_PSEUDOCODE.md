# Photo Caption Component

## Goal
Create a reusable PhotoCaption component for adding labels and handwritten-style notes to images in UFO documents.

## Key Features
- Strong label for identification
- Handwritten-style note text
- High z-index for overlay positioning
- Scribble styling for authentic look

## Implementation
1. Create TypeScript interface for props
2. Use existing CSS classes (caption, label, note, scribble)
3. Export as reusable component
4. Add to components index
