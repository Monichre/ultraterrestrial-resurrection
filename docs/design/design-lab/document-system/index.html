05

Operating rules

The system stays useful by refusing both fake antiquity and generic dashboard chrome.

Material before mood

Paper denotes a record, source, or field artifact. It is not a universal sepia wash.

Spot ink is semantic

Cobalt registers analysis, green records support, and red exposes contradiction.

Texture stays quiet

Raster grain remains subordinate to text contrast, keyboard focus, and print output.

One physical signature

The exposure beam and registration cross carry identity. Extra vintage garnish gets cut.

Provenance is visible

Solid rules contain sourced material. Dashed cobalt rules contain analytical inference.

Closure stays earned

Every synthesis protects the counter-reading and leaves a falsifiable next trace.
